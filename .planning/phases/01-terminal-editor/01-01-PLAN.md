3. Create `src/editor.rs` — a wrapper around `ratatui_textarea::TextArea` that provides:

- `Editor` struct containing:
  - `textarea: TextArea<'a>` — the ratatui-textarea widget
  - `modified: bool` — tracks whether content has changed since last save
  - `filepath: Option<PathBuf>` — the file path (None for untitled buffers per D-02)

- `Editor::new(content: Option<String>, filepath: Option<PathBuf>) -> Editor` constructor:
  - If content is Some, split by lines into `Vec<String>`, pass to `TextArea::new(lines)`
  - If content is None, use `TextArea::default()` for empty buffer (per D-02)
  - Set line number style: `textarea.set_line_number_style(Style::default().fg(Color::DarkGray))` (per D-08)
  - Set `modified = false`

- `Editor::handle_key(&mut self, key: KeyEvent) -> Option<EditorAction>` method implementing ALL keybindings per D-05, D-06, D-07:
  - `(CONTROL, Char('s'))` -> return `Some(EditorAction::Save)`
  - `(CONTROL, Char('q'))` -> return `Some(EditorAction::RequestQuit)`
  - `(CONTROL, Char('z'))` -> call `self.textarea.undo()`, return `Some(EditorAction::ContentChanged)`
  - `(CONTROL, Char('y'))` -> call `self.textarea.redo()`, return `Some(EditorAction::ContentChanged)`
  - `(CONTROL, Left)` -> call `self.textarea.move_cursor(CursorMove::WordBack)`, return None
  - `(CONTROL, Right)` -> call `self.textarea.move_cursor(CursorMove::WordForward)`, return None
  - `(NONE, Home)` -> call `self.textarea.move_cursor(CursorMove::Head)`, return None
  - `(NONE, End)` -> call `self.textarea.move_cursor(CursorMove::End)`, return None
  - `(CONTROL, Home)` -> call `self.textarea.move_cursor(CursorMove::Top)`, return None
  - `(CONTROL, End)` -> call `self.textarea.move_cursor(CursorMove::Bottom)`, return None
  - `(CONTROL, Char('c'))` -> return None (do nothing, per D-07)
  - All other keys -> call `self.textarea.input_without_shortcuts(key)`, if return is true set `self.modified = true` and return `Some(EditorAction::ContentChanged)`, else return None
  - CRITICAL: Use `input_without_shortcuts()` NOT `input()` to avoid Emacs keybinding conflicts (per research Pitfall 2)

- `EditorAction` enum: `Save`, `RequestQuit`, `ContentChanged`

- `Editor::content(&self) -> String` — returns `self.textarea.lines().join("\n")`
- `Editor::cursor_position(&self) -> (usize, usize)` — returns `self.textarea.cursor()` (row, col)
- `Editor::is_modified(&self) -> bool`
- `Editor::mark_saved(&mut self)` — sets `modified = false`
- `Editor::display_name(&self) -> &str` — returns filename from filepath or "[untitled]" per D-02
- `Editor::widget(&self) -> &TextArea` — returns reference for rendering

4. Create a minimal `src/main.rs` with clap derive (per D-04):
```rust
use anyhow::Result;
use clap::Parser;
use std::path::PathBuf;

mod app;
mod editor;

#[derive(Parser)]
#[command(name = "mdedit", about = "A terminal markdown editor")]
struct Cli {
    /// File to edit
    file: Option<PathBuf>,
}

fn main() -> Result<()> {
    let cli = Cli::parse();
    // Load file content if path provided (per D-01)
    let content = if let Some(ref path) = cli.file {
        match std::fs::read_to_string(path) {
            Ok(c) => Some(c),
            Err(e) if e.kind() == std::io::ErrorKind::NotFound => None, // create on save per D-01
            Err(e) => return Err(e.into()),
        }
    } else {
        None
    };

    ratatui::run(|terminal| {
        let mut app = app::App::new(content, cli.file);
        app.run(terminal)
    })?;
    Ok(())
}
```

3. `App::new(content: Option<String>, filepath: Option<PathBuf>) -> App`:
   - Create Editor with content and filepath
   - Set mode to Editing, should_quit to false

4. `App::run(&mut self, terminal: &mut ratatui::DefaultTerminal) -> Result<()>`:
   - Main event loop (per research skeleton):
   - Loop: `terminal.draw(|frame| self.render(frame))?;`
   - Poll events with `event::poll(Duration::from_millis(50))?`
   - On `Event::Key(key)` with `key.kind == KeyEventKind::Press` (IMPORTANT: filter for Press only to avoid double-handling on Windows/some terminals):
     - Match on `self.mode`:
       - `Editing`: call `self.editor.handle_key(key)` and process the returned `EditorAction`
         - `Save` -> call save logic (stub for now — will be wired in Plan 02, just set a TODO comment)
         - `RequestQuit` -> if `self.editor.is_modified()` set mode to ConfirmQuit, else set `should_quit = true`
         - `ContentChanged` -> no-op (status bar will read modified flag)
         - `None` -> no-op
       - `ConfirmQuit`: handle y/n/Esc keys per D-13 (save stub for y, quit for n, cancel for Esc)
       - `PromptFilename`: handle text input for filename (simple String buffer, Enter to confirm, Esc to cancel)
   - On `Event::Resize(_, _)`: no-op — ratatui re-renders on next draw() automatically (per FOUND-06)
   - Check `self.should_quit` to break loop

5. `App::render(&self, frame: &mut Frame)`:
   - Create vertical layout with:
     - `Constraint::Fill(1)` for editor area
     - `Constraint::Length(1)` for status bar area
   - Render editor widget: `frame.render_widget(self.editor.widget(), chunks[0])`
   - Render status bar area:
     - In `Editing` mode: render a simple Paragraph with filename and cursor position (temporary — Plan 02 adds the full StatusBar widget)
       - Format: ` {display_name}{modified} | Ln {row+1}, Col {col+1}` where modified is " [+]" if modified, empty otherwise (per D-15)
       - Style: `Style::default().bg(Color::DarkGray).fg(Color::White)` (or similar — use terminal-friendly colors per D-10)
     - In `ConfirmQuit` mode: render "Unsaved changes. Save? (y/n/Esc)" per D-13
     - In `PromptFilename` mode: render "Save as: {input_buffer}_" with cursor

6. Process exit codes: the run() method returns Ok(()) for clean exit (exit code 0 per D-03). Errors propagate via anyhow (exit code 1).
