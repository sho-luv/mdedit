Create the two new modules.

**src/file_io.rs** — Atomic file operations (per research Pattern 3):

1. `pub fn save_file(path: &Path, content: &str) -> anyhow::Result<()>`:
   - Write content to a temp file at `path.with_extension("mdedit-tmp")`
   - Use `std::fs::write(&tmp, content)?`
   - Rename temp to target: `std::fs::rename(&tmp, path)?`
   - Return Ok(())
   - On error, attempt to clean up the temp file (best-effort `let _ = std::fs::remove_file(&tmp)`)

2. `pub fn load_file(path: &Path) -> anyhow::Result<Option<String>>`:
   - If file exists, read and return `Some(content)`
   - If file not found (ErrorKind::NotFound), return `Ok(None)` — file will be created on first save per D-01
   - Other errors: propagate with `?`

**src/status_bar.rs** — Status display widget (per research Pattern 5 and D-12, D-15):

1. `StatusBar` struct:
   - `timed_message: Option<(String, Instant)>` — message with timestamp
   - `message_duration: Duration` — set to `Duration::from_secs(2)` in constructor

2. `StatusBar::new() -> StatusBar`

3. `StatusBar::set_message(&mut self, msg: &str)`:
   - Set `self.timed_message = Some((msg.to_string(), Instant::now()))`

4. `StatusBar::render(&self, frame: &mut Frame, area: Rect, filename: &str, cursor: (usize, usize), modified: bool)`:
   - Check if timed message is still active (elapsed < message_duration)
   - If active timed message: display the message text centered or left-aligned
   - If no active message: display normal status line
   - Normal format: ` {filename}{mod_indicator} | Ln {row+1}, Col {col+1}`
     - `mod_indicator` is ` [+]` if modified, empty string otherwise (per D-15)
   - Render as a `Paragraph` widget with style `Style::default().bg(Color::DarkGray).fg(Color::White)`
   - The filename goes on the left, cursor position on the right — use `Line::from(vec![left_span, spacer, right_span])` or a two-column Layout

5. `StatusBar::is_message_active(&self) -> bool` — returns true if a timed message is showing (used by event loop to know if redraw needed for message expiry)

**src/app.rs changes:**

1. Add `status_bar: StatusBar` field to App struct. Import `crate::status_bar::StatusBar` and `crate::file_io`.

2. Add `filename_input: String` field for the PromptFilename mode's text buffer.

3. Update `App::new()` to initialize StatusBar.

4. **Wire Save action (Ctrl+S handler) per D-12:**
   - When editor returns `EditorAction::Save`:
     - If `self.editor.filepath` is Some: call `file_io::save_file(&path, &self.editor.content())?`, then `self.editor.mark_saved()`, then `self.status_bar.set_message("Saved")`
     - If `self.editor.filepath` is None: switch to `AppMode::PromptFilename` mode, set `self.filename_input = String::new()`

5. **Wire ConfirmQuit mode per D-13:**
   - 'y'/'Y': save (same logic as Ctrl+S — if filepath exists, save and quit; if no filepath, switch to PromptFilename with a flag to quit after save), then `self.should_quit = true`
   - 'n'/'N': `self.should_quit = true` (quit without saving)
   - Esc: `self.mode = AppMode::Editing` (cancel quit)
   - All other keys: ignored

6. **Wire PromptFilename mode per D-02:**
   - Printable chars: append to `self.filename_input`
   - Backspace: pop from `self.filename_input`
   - Enter: if `self.filename_input` is not empty, set `self.editor.filepath = Some(PathBuf::from(&self.filename_input))`, call save logic, switch back to Editing mode. If there's a pending quit flag, set `self.should_quit = true`.
   - Esc: cancel, switch back to Editing (or ConfirmQuit if came from there)

7. **Update render() to use StatusBar:**
   - Replace the inline Paragraph status rendering with `self.status_bar.render(frame, chunks[1], self.editor.display_name(), self.editor.cursor_position(), self.editor.is_modified())`
   - In ConfirmQuit mode, render the prompt text in the status bar area instead: `" Unsaved changes. Save? (y/n/Esc)"` with a distinct background color (e.g., `Color::Red` or `Color::Yellow` background)
   - In PromptFilename mode, render `" Save as: {filename_input}_"` in the status bar area

8. **Exit code handling per D-03:** main.rs already returns Result — Ok(()) = exit 0, Err = exit 1 via anyhow. No changes needed.
