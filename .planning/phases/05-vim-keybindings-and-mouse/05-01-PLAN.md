**1. Create `src/vim.rs`** with the VimHandler state machine (per D-01, D-04):

```rust
// VimMode: the four modal states
pub enum VimMode {
    Normal,
    Insert,
    Visual { line_wise: bool },  // D-13, D-14: char-wise vs line-wise
    Command,
}

// VimCommand: actions the handler returns for the app/editor to execute
pub enum VimCommand {
    // Motion commands
    Move(CursorMove),
    MoveN(CursorMove, usize),  // motion with count
    // Editing commands
    Delete { motion: Motion },
    Change { motion: Motion },
    Yank { motion: Motion },
    PasteAfter,
    PasteBefore,
    DeleteChar,          // x
    // Insert mode entry variants (D-09)
    EnterInsert(InsertPosition),
    ExitInsert,          // Esc from Insert
    // Visual mode
    EnterVisual { line_wise: bool },
    ExitVisual,
    VisualDelete,
    VisualChange,
    VisualYank,
    VisualIndent,
    VisualOutdent,
    // Command mode
    EnterCommand,
    ExitCommand,
    CommandExecute(String),  // the typed command string
    CommandAppend(char),
    CommandBackspace,
    // Other
    Undo,
    Redo,
    EnterSearch,         // / in normal mode -> reuse existing Search
    Save,                // from :w
    Quit { force: bool },// from :q or :q!
    SaveAndQuit,         // from :wq
    ContentChanged,      // signal to app that content changed
    None,                // no-op (key consumed but no action needed)
}

// Motion: represents a vim motion target for operators
pub enum Motion {
    Left, Right, Up, Down,
    WordForward, WordBack, WordEnd,
    LineStart, LineEnd,
    FileStart, FileEnd,
    ParagraphUp, ParagraphDown,
    Line,  // dd, yy, cc - operates on current line(s)
    ToEnd, // D, C, d$, c$
    ToStart, // d0
}

// InsertPosition: how insert mode was entered (D-09)
pub enum InsertPosition {
    BeforeCursor,   // i
    AfterCursor,    // a
    LineStart,      // I
    LineEnd,        // A
    NewLineBelow,   // o
    NewLineAbove,   // O
}

pub struct VimHandler {
    pub mode: VimMode,
    pending_operator: Option<Operator>,  // d, c, y waiting for motion
    count_prefix: Option<usize>,         // accumulated count digits (D-08)
    partial_key: Option<char>,           // e.g., 'g' waiting for 'g'
    yank_register: String,               // single register for Phase 6 clipboard
    command_buffer: String,              // text typed after ':'
}
```

Implement `VimHandler::new() -> Self` (starts in Normal mode).

Implement `VimHandler::handle_key(&mut self, key: KeyEvent) -> VimCommand`:
- For this plan, implement ONLY the mode switching skeleton:
  - In Normal mode: `i` returns `EnterInsert(BeforeCursor)`, `Esc` is no-op, `:` returns `EnterCommand`, `v` returns `EnterVisual{line_wise: false}`, `V` returns `EnterVisual{line_wise: true}`, `/` returns `EnterSearch`. Digit keys (1-9, then 0) accumulate into count_prefix. ALL OTHER keys return `VimCommand::None` for now (Plans 02 and 03 will fill them in).
  - In Insert mode: `Esc` returns `ExitInsert` and sets mode to Normal. All other keys return `VimCommand::None` (app.rs will forward them to `textarea.input_without_shortcuts()`).
  - In Visual mode: `Esc` returns `ExitVisual` and sets mode to Normal. All other keys return `VimCommand::None` for now.
  - In Command mode: `Esc` returns `ExitCommand` and sets mode to Normal. `Enter` parses command_buffer and returns appropriate command. Char keys append to command_buffer. Backspace removes last char.

Implement `VimHandler::mode(&self) -> &VimMode`.
Implement `VimHandler::command_buffer(&self) -> &str`.
Implement `VimHandler::reset_count(&mut self)` to clear count_prefix after use.
Implement `VimHandler::take_count(&mut self) -> usize` returning count_prefix.unwrap_or(1) and clearing it.

Update the event loop's match on `self.mode`:

```rust
match self.mode {
    AppMode::Editing => self.handle_editing_key(key),  // nano mode

    AppMode::Insert => self.handle_vim_insert_key(key),
    AppMode::Visual => self.handle_vim_visual_key(key),
    AppMode::Command => self.handle_vim_command_key(key),
    AppMode::ConfirmQuit => self.handle_confirm_quit_key(key),
    AppMode::PromptFilename => self.handle_prompt_filename_key(key),
    AppMode::Search => self.handle_search_key(key),

```

Create stub methods that delegate to VimHandler:

`handle_vim_key()`: Call `vim_handler.handle_key(key)`, then match on returned VimCommand. For now, handle `EnterInsert` (set mode to AppMode::Insert), `EnterCommand` (set mode to AppMode::Command), `EnterVisual` (set mode to AppMode::Visual), `EnterSearch` (set mode to AppMode::Search, reusing existing search infrastructure per D-25), `VimCommand::None` (no-op). All other commands log or ignore for now.

`handle_vim_insert_key()`: Call `vim_handler.handle_key(key)`. If `ExitInsert`, set mode to `AppMode::Normal`. Otherwise, pass key to `self.editor.textarea_mut().input_without_shortcuts(key)` (per D-03) and if content changed, set `content_dirty = true` and `last_edit_time`.

`handle_vim_visual_key()`: Call `vim_handler.handle_key(key)`. If `ExitVisual`, cancel selection and set mode to Normal. Otherwise no-op for now.

`handle_vim_command_key()`: Call `vim_handler.handle_key(key)`. Handle `ExitCommand` (mode = Normal), `CommandExecute` (parse `:w`, `:q`, `:wq`, `:q!` and call `do_save()`, set `should_quit`, etc.), `CommandAppend`/`CommandBackspace` (no-op, handler maintains buffer).

For vim modes, add render branches in `App::render()`:
```rust
AppMode::Normal => {
    let mode_info = Some(("-- NORMAL --", self.theme.mode_normal_bg));
    self.status_bar.render(frame, status_area, self.editor.display_name(),
        self.editor.cursor_position(), self.editor.is_modified(), &self.theme, mode_info);
}
AppMode::Insert => {
    let mode_info = Some(("-- INSERT --", self.theme.mode_insert_bg));
    self.status_bar.render(frame, status_area, self.editor.display_name(),
        self.editor.cursor_position(), self.editor.is_modified(), &self.theme, mode_info);
}
AppMode::Visual => {
    let mode_info = Some(("-- VISUAL --", self.theme.mode_visual_bg));
    self.status_bar.render(frame, status_area, self.editor.display_name(),
        self.editor.cursor_position(), self.editor.is_modified(), &self.theme, mode_info);
}
AppMode::Command => {
    // Command mode renders :{buffer}_ instead of normal status
    let cmd = self.vim_handler.as_ref().map(|h| h.command_buffer()).unwrap_or("");
    let prompt = format!(":{}_", cmd);
    let bar = Paragraph::new(Span::raw(prompt))
        .style(Style::default().bg(self.theme.mode_command_bg).fg(self.theme.status_bar_fg));
    frame.render_widget(bar, status_area);
}
```
