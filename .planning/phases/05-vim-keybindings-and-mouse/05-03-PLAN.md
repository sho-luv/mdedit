**1. Add `handle_visual_key()` to VimHandler** in `src/vim.rs`:

When in `VimMode::Visual { line_wise }`:

Motion keys extend selection (same motions as Normal mode, per D-13):
- `h/j/k/l/w/b/e/0/$` -> Return corresponding `VimCommand::MoveN()` or `VimCommand::Move()`. The app will execute the motion while selection is active, extending it.
- `gg` -> `VimCommand::Move(CursorMove::Top)`
- `G` -> `VimCommand::Move(CursorMove::Bottom)`

Operator keys act on selection (D-15):
- `d` -> Return `VimCommand::VisualDelete`. Set mode to Normal.
- `c` -> Return `VimCommand::VisualChange`. Set mode to Normal (will transition to Insert in app).
- `y` -> Return `VimCommand::VisualYank`. Set mode to Normal.
- `>` -> Return `VimCommand::VisualIndent`. Stay in Visual mode.
- `<` -> Return `VimCommand::VisualOutdent`. Stay in Visual mode.

Mode exit:
- `Esc` -> Return `VimCommand::ExitVisual`. Set mode to Normal.
- `v` (when in char-wise Visual) -> Return `VimCommand::ExitVisual`. Set mode to Normal.
- `V` (when in line-wise Visual) -> Return `VimCommand::ExitVisual`. Set mode to Normal.

**2. Wire Visual mode commands in `App::execute_vim_command()`** in `src/app.rs`:

Update the match arms for Visual commands:

```rust
VimCommand::VisualDelete => {
    // Yank selected text to register first
    if let Some(text) = self.editor.selected_text() {
        if let Some(ref mut handler) = self.vim_handler {
            handler.set_yank_register(text);
        }
    }
    // Delete selection using textarea's built-in delete behavior
    // When selection is active, insert_str("") or delete_next_char deletes selected text
    self.editor.textarea_mut().delete_str();  // or use cut/delete approach
    self.editor.textarea_mut().cancel_selection();
    self.mark_content_changed();
    self.mode = AppMode::Normal;
}
VimCommand::VisualChange => {
    // Same as delete but enter Insert mode
    if let Some(text) = self.editor.selected_text() {
        if let Some(ref mut handler) = self.vim_handler {
            handler.set_yank_register(text);
        }
    }
    self.editor.textarea_mut().delete_str();
    self.editor.textarea_mut().cancel_selection();
    self.mark_content_changed();
    self.mode = AppMode::Insert;
}
VimCommand::VisualYank => {
    if let Some(text) = self.editor.selected_text() {
        if let Some(ref mut handler) = self.vim_handler {
            handler.set_yank_register(text);
        }
    }
    self.editor.textarea_mut().cancel_selection();
    self.mode = AppMode::Normal;
}
VimCommand::VisualIndent => {
    // Get selection range, indent those lines
    if let Some(((sr, _), (er, _))) = self.editor.textarea_mut().selection_range() {
        // Use existing indent_lines helper or replicate logic
        // Insert 2 spaces at start of each line in range
        for row in sr..=er {
            self.editor.textarea_mut().move_cursor(CursorMove::Jump(row as u16, 0));
            self.editor.textarea_mut().insert_str("  ");
        }
        self.mark_content_changed();
    }
}
VimCommand::VisualOutdent => {
    // Similar: remove up to 2 leading spaces from each selected line
    if let Some(((sr, _), (er, _))) = self.editor.textarea_mut().selection_range() {
        for row in sr..=er {
            let line = self.editor.textarea_mut().lines()[row].clone();
            let spaces = line.chars().take(2).take_while(|c| *c == ' ').count();
            if spaces > 0 {
                self.editor.textarea_mut().move_cursor(CursorMove::Jump(row as u16, 0));
                for _ in 0..spaces {
                    self.editor.textarea_mut().delete_next_char();
                }
            }
        }
        self.mark_content_changed();
    }
}
```

Note: For deleting selected text, investigate what textarea API is available. If `textarea.delete_str()` doesn't exist, the pattern is: when a selection is active, `textarea.insert_char(' ')` then `textarea.delete_char()` replaces the selection. Or check if `textarea.cut()` is available. Read the textarea source/docs. The safest approach may be to insert an empty string which in some textarea implementations deletes the selection, or to use `textarea.input_without_shortcuts()` with a Delete key event.

```rust
fn handle_vim_visual_key(&mut self, key: KeyEvent) {
    // Ctrl+P still toggles layout
    if key.modifiers == KeyModifiers::CONTROL && key.code == KeyCode::Char('p') {
        self.layout_mode = self.layout_mode.next();
        self.status_bar.set_message(self.layout_mode.label());
        return;
    }
    let cmd = self.vim_handler.as_mut().map(|h| h.handle_key(key)).unwrap_or(VimCommand::None);
    self.execute_vim_command(cmd);
}
```
