**1. Create `src/clipboard.rs` (~150-200 lines) per D-01 through D-04, D-09 through D-12:**

Define a `ClipboardProvider` trait with `write(&self, text: &str) -> Result<(), String>`, `read(&self) -> Result<String, String>`, and `name(&self) -> &str`.

Implement three provider types:
- `Osc52Writer` — writes OSC 52 escape `\x1b]52;c;{base64}\x07` to stdout. If `in_tmux` is true, wrap in DCS passthrough `\x1bPtmux;\x1b\x1b]52;c;{base64}\x07\x1b\\`. Per D-09, `read()` always returns `Err`. Per D-10, no size limit. Per D-11, no capability detection.
- `NativeProvider` enum (MacOs, Wayland, Xclip, Xsel) — implements write via `Command::new("pbcopy"/"wl-copy"/"xclip -selection clipboard"/"xsel --clipboard --input")` with piped stdin. Implements read via `Command::new("pbpaste"/"wl-paste"/"xclip -selection clipboard -o"/"xsel --clipboard --output")` capturing stdout.
- `CompositeProvider` — holds `Osc52Writer` + `Option<NativeProvider>`. `write()` sends to OSC 52 first (primary per D-01), then best-effort to native. `read()` delegates to native, returns Err if none.

Add `detect_provider() -> Box<dyn ClipboardProvider>` function per D-02, D-03:
- Detect `$TMUX` env var for tmux passthrough (per D-12, detect once at startup).
- macOS: `cfg!(target_os = "macos")` → NativeProvider::MacOs (pbcopy always present).
- Linux Wayland: `$WAYLAND_DISPLAY` set + `command_exists("wl-copy")` → NativeProvider::Wayland.
- Linux X11: `$DISPLAY` set + `command_exists("xclip")` → NativeProvider::Xclip, else `command_exists("xsel")` → NativeProvider::Xsel.
- Return `CompositeProvider { writer: Osc52Writer { in_tmux }, reader: native }`.

Include an inline `base64_encode(input: &[u8]) -> String` function (~20 lines). Do NOT add line breaks in output (Pitfall 5 from research). Do NOT add the `base64` crate.

Include `command_exists(name: &str) -> bool` helper using `Command::new("which")`.

**1. Create `yank_to_clipboard` helper method on App per D-05, D-08:**

```rust
fn yank_to_clipboard(&mut self, text: &str) {
    // Write to internal vim register
    if let Some(ref mut handler) = self.vim_handler {
        handler.set_yank_register(text.to_string());
    }
    // Write to system clipboard
    if let Err(_e) = self.clipboard.write(text) {
        if !self.clipboard_warned {
            self.status_bar.set_message("System clipboard unavailable - using internal register");
            self.clipboard_warned = true;
        }
    }
}
```

**4. Add nano mode Ctrl+C / Ctrl+V per D-07:**

In `handle_editing_key()` (the nano mode key handler), add handling BEFORE the existing key dispatch:
- `Ctrl+C`: Get current selection text from textarea. If selection exists, call `self.clipboard.write(&selected_text)`. Show status "Copied to clipboard". If no selection, do nothing (or copy current line).

Note: Ctrl+C in raw terminal mode is just `KeyCode::Char('c')` with CONTROL modifier -- it does NOT send SIGINT (Pitfall 3 from research).


This handles terminal-level paste (Cmd+V / Ctrl+Shift+V) which crossterm delivers as a single `Event::Paste` when bracketed paste is enabled. Insert directly regardless of vim mode -- the user explicitly pasted via terminal shortcut (per research recommendation).
